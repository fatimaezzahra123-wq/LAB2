#  LAB2 - Calculateur d'impôts locaux
## Description
Application Android qui calcule le montant des impôts locaux d'une habitation en fonction de :

-  Le nom du propriétaire
-  L'adresse de la propriété
- La surface de la maison (en m²)
- Le nombre de pièces
- La présence ou non d'une piscine

##  Formule de calcul

| Composante | Calcul |
| Impôt de base | Nombre de pièces × 60 DH |
| Impôt supplémentaire | Surface × 2.5 DH |
| Taxe piscine | + 100 DH si piscine cochée |
| **Impôt Total** | **Base + Supplémentaire + Piscine** |
